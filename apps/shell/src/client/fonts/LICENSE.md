# Fonts

Both families are licensed under the **SIL Open Font License 1.1**, which
explicitly permits embedding in and serving from a web page, commercial use
included. The full licence text for each is checked in beside the font files,
because the OFL requires the copyright notice and the licence to accompany the
Font Software wherever it is redistributed — and self-hosting is redistribution.

The files are the Latin subsets published by Google Fonts, used unmodified, and
served from our own origin so the page opens no third-party connection and the
CSP keeps `font-src 'self'`.

Neither family declares a Reserved Font Name, so a modified or further-subset
version would not have to be renamed. Nothing here modifies them.

What the licence does not allow, for the avoidance of doubt: selling the fonts
on their own, and redistributing them under a different licence.
